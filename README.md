# スキー場3Dビューア

日本のスキー場を3D地形の上で眺めたり、リフトやコースに沿って空中を飛ぶように見られるWebアプリのプロトタイプです。

対応エリア(試作):
- **白馬バレー**(長野県):白馬コルチナ・白馬乗鞍温泉・栂池高原・白馬岩岳・白馬八方尾根・Hakuba47・エイブル白馬五竜・白馬さのさか・鹿島槍・爺ガ岳の10スキー場
- **ニセコ**(北海道):花園・グラン・ヒラフ・ビレッジ・アンヌプリ国際・モイワ
- **安比高原**(岩手県)

## できること

- スキー場を選ぶと、その場所へカメラが飛んで3D表示
- コースを難易度別に色分け(初級=緑、中級=赤、上級=黒、非圧雪=オレンジ)、リフトは黄色の破線
- **冬景色モード**(初期表示):航空写真を雪景色風に加工し、雪面の陰影・圧雪ゲレンデの白い帯・降雪エフェクトを表示。「夏」ボタンで元の航空写真に戻せる
- **コースをクリック** → 詳細カードを表示
  - コース名・難易度・全長・標高差・スタート/ゴール標高・最大斜度・平均斜度・整備状況(圧雪/コブ/非圧雪)・ナイター
  - 標高プロファイル(高低図)と、斜度などから自動生成した「どんなコースか」の説明文
  - 「このコースを滑る」で山頂側から滑り降りる視点のフライスルー(高低図上に現在地を表示)
- **リフトをクリック** → 種類・全長・標高差・乗車時間の目安などを表示し、「乗ってみる」で山麓から山頂へ乗車する視点のフライスルー
- 地図上のコース・リフトにマウスを乗せると名前を表示
- **スキー場名の表示**:地図上に各スキー場の名前(コース数・リフト数つき)を表示。名前をクリックするとそのスキー場へ移動し、コース・リフト一覧をそのスキー場だけに絞り込み。「すべて」表示ではスキー場ごとに見出しを付けて一覧表示。詳細カードやマウスを乗せたときの表示にもスキー場名が出る
- **いろんな角度から見る**
  - 視点プリセット: 「北から/東から/南から/西から」見る方角、「真上/斜め/低空」の角度をワンタップで切替
  - 「↺ 左 / 右 ↻ / ⤒ 上へ / ⤓ 下へ」ボタンを押している間、回転・傾き(スマホ向け)。右ドラッグ・2本指でも可
  - フライト中のカメラ: 「後ろから(追従)/一人称/横から/上空から」を飛行中でも切替可能
  - フライト中はドラッグで滑走者の周りを回り込み、上下ドラッグで高さ、ホイールで距離を調整。「視点を戻す」で元に戻る
- **空撮で一周** → スキー場の周りを旋回
- 速度・起伏の強調度を調整可能。地図をドラッグするとフライトは止まる

## 動かし方

ビルド不要の静的サイトです。ローカルで確認する場合:

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

GitHub Pages(Settings → Pages → Branch を選択)でそのまま公開することもできます。
`?resort=niseko` のようにURLでスキー場を指定できます。

## スキー場の追加

`resorts.js` に名前・中心座標・取得範囲(bbox)を追加するだけで一覧に表示されます。
`areas` にエリア内のスキー場名を書いておくと、OpenStreetMap のスキー場範囲(`landuse=winter_sports`)と名前で照合し、コース・リフトをスキー場ごとに振り分けます。OSM に範囲が無いスキー場は `center` の近くのものを割り当て、定義に無い名前付きのスキー場は自動で追加されます。

## コースデータの取得に失敗したとき

コース・リフトのデータは、表示するたびに OpenStreetMap の無料サーバー(Overpass API)から取得しています。
このサーバーは世界中で共用されているため、混雑していると取得に失敗することがあります。

1. 表示されたメッセージの下の **「↻ 再試行」** を押す(1〜2分おくと成功しやすい)
2. インターネット接続を確認する
3. 一度取得できたデータはブラウザに7日間保存され、次回からは通信なしで表示される。期限切れ後に取得に失敗した場合は、保存済みの古いデータを表示する
4. それでも失敗が続く場合は時間帯を変える(日本の夕方〜夜は欧州の日中にあたり混みやすい)

※ アプリは3台のサーバーを順番に試し、1台あたり最大90秒で打ち切る。

## 制約

- コース・リフトの精度は OpenStreetMap の登録状況に依存します
- 航空写真は雪の無い時期のものです(冬景色は加工による表現で、実際の積雪状況ではありません)
- 標高・斜度は約10mメッシュの標高データからの推定値で、実際の最大斜度より小さめに出ることがあります
- 地形は約10mメッシュのため、木や建物は立体になりません
